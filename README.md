Dashboard de Análise de RH
Sobre o Projeto
Este projeto foi desenvolvido com foco em análise estratégica de RH (HR Analytics), utilizando Python e Tableau para transformar dados operacionais em insights voltados à retenção de talentos e tomada de decisão.
O objetivo principal foi analisar padrões de turnover, comportamento organizacional, engajamento e equilíbrio entre vida pessoal e trabalho, além de identificar funcionários com maior risco de saída.

Objetivos do Projeto
Analisar turnover organizacional
Identificar departamentos críticos
Avaliar engajamento e satisfação dos colaboradores
Explorar padrões comportamentais por faixa etária
Criar classificação de risco de saída
Desenvolver dashboard executivo interativo

 Principais Análises
 Turnover por Departamento
Identificação dos departamentos com maior taxa de saída.
 Engajamento e Satisfação
Análise da relação entre engajamento, satisfação e permanência dos funcionários.
 Work-Life Balance
Avaliação do equilíbrio entre vida pessoal e profissional por faixa etária.
Classificação de Risco
Criação de um modelo heurístico simples para identificar funcionários com potencial risco de saída.

 Principais Insights
O departamento de Production apresentou o maior turnover da empresa.
Funcionários com menor Work-Life Balance apresentaram maior tendência de saída.
A faixa etária entre 30 e 40 anos demonstrou maior estabilidade.
Colaboradores classificados como “Alto Risco” concentraram menores índices de engajamento.

O dashboard foi desenvolvido no Tableau com foco executivo e analítico.
